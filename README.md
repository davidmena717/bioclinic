# BioClinic

Landing page estática para BioClinic, creada a partir de la identidad visual compartida por la clínica.

## Archivos

- `index.html`: sitio adaptable a móviles con navegación, presentación, especialidades y enfoque de atención.
- `assets/bioclinic-logo.png`: imagen del logo proporcionada para el proyecto.

## Contacto y datos clínicos

La página evita publicar dirección, teléfono, horarios o especialidades concretas porque esos datos no se incluyeron en el material inicial. Actualízalos con información confirmada antes de usar el sitio como canal de atención.
